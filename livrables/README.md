Les rapports décrivent les fonctionnalités et les vérifications disponibles dans les projets. Les captures d'écran doivent être prises pendant une démonstration réelle ; aucune capture n'est fabriquée ou incluse dans les rapports.

Les archives contiennent le code, les guides, les collections Postman et les tests lorsqu'ils existent. Elles excluent les dépendances installées, les fichiers de compilation, les répertoires Git et les fichiers `.env` locaux. Pour le LAB4, générer localement les secrets et identifiants conformément au README ; ne jamais les ajouter à l'archive ou aux captures.
